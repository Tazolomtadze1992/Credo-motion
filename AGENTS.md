# Credo Motion Lab

For Credo interaction design, animation implementation, or motion review, read
[the motion guide](docs/motion-guide.md). Read the relevant case study linked
there before changing an existing interaction. Use these project decisions
alongside applicable animation skills; current user instructions take precedence.

Keep new Credo work in this Next.js project. The earlier standalone HTML is a
historical reference.

After meaningful animation work, record demonstrated lessons in the guide's
study notes. Distinguish user-approved decisions, observations, experiments,
and unresolved questions. Do not turn one screen's timing into a universal rule,
claim approval on the user's behalf, or record an untested assumption as a fact.
Review-only requests remain read-only unless the user asks to save findings.
